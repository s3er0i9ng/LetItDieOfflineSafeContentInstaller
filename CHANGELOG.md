# Changelog

## Version 3.53

- Added three Gravity Rush 2 decals: **Apple**, **Dusty**, and **Panther Mode**.
- Added updated full-, medium-, and small-size UI artwork so supported
  collaboration decals display correctly in the Mushroom Club, inventory, and
  HUD.
- Expanded the verified artwork collection to 105 native-LZO packages for 35
  collaboration decals.
- Retained all previously supported decal artwork and the seven safe blueprint
  quest routes.
- Kept decal acquisition pool-only; this release does not add decal giveaway
  quests.
- Removed the experimental asset-swapped blueprint content so it can continue
  as a separate project.

Special thanks to **ZeroUnderOne** for the help and support.
